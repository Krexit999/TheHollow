# THE HOLLOW — Vision note: Reset Layers vs Prestige Layers
(This is a note for ME, not for Claude Code. It's the direction, not a build spec.)

## The core realization
The game currently has FOUR RESET LAYERS and ZERO PRESTIGE LAYERS.
Collapse / Breach / Recursion / Spiral all just wipe progress below them for a currency.
Even Recursion — the "big reset" — doesn't make the game meaningfully FASTER next time.
So a second climb feels like re-doing the whole game. That's the thing to fix.

## The two kinds of layer (the GCI / AdVenture-Capitalist model)

**RESET LAYERS (have these, keep them):**
- Small, frequent, local. Reset run/shell progress for a currency (Cores, Echoes).
- Collapse and Breach are fine as reset layers.

**PRESTIGE LAYERS (missing — the real want):**
- Global. Bank a currency, spend it on a MASSIVE boost.
- The boost makes every earlier system AND every reset layer dramatically faster/easier.
- The next climb is NOT a re-grind — it's the same game at huge speed because you're powered.
- A prestige currency you spend on big permanent multipliers/unlocks, not a soft reset.

## How the ladder should feel
- Play a World actively → it has its own small reset layers (local currency, quick loops).
- Eventually prestige → huge global boost → earlier Worlds/systems trivialize.
- After Recursion, doing SOMETHING (a milestone, not necessarily finishing again) unlocks
  the NEXT PRESTIGE LAYER → which opens a NEW WORLD (not a shell).
- New Worlds are where the NEW SYSTEMS we want to add will live.

## Hard rules for the prestige design
- Prestige must make re-climbing HUGELY faster. Not 2x. Blow-through-the-old-content faster.
- You should NOT have to redo the whole game to prestige — maybe partially, but the payoff
  is speed, not repetition. A big-boost currency, spent on power.
- Unlocking the next prestige layer is gated on a MILESTONE, not on reaching the very end
  again. "Do this thing" → next World opens.
- Worlds ≠ Shells. Shells are the 7 layers of one descent. Worlds are the big prestige-gated
  expansions that hold future content.

## On idle (correction to earlier direction)
- The game is NOT idle-first. It's ACTIVE-first with idle as a secondary mode.
- You play actively; once you've set things up, you CAN idle for a while — but you can't
  beat the game (or a wall) purely by idling from the start.
- So: idle stays VIABLE (pillar 1 holds — never fully blocked), but stop optimizing toward
  "idle reaches ~5x of active everywhere." Active is the intended primary path. Idle is the
  "step away and come back to progress," not the "leave it running and win" path.
- Practically: don't lean the whole economy on the idle ratio. Tune for a fun ACTIVE loop
  first; keep idle a valid slower fallback, not the design center.

## Where this sits vs current work
- FRONT OF THE GAME FIRST. Fix Loam→Glassmere feel, the reskin problem, the lookup problem,
  legibility — the stuff found by playing. Get the early game genuinely fun and active.
- THEN the prestige-layer architecture — it's a big structural add and it wants the front
  solid underneath it.
- New Worlds + new systems come AFTER the prestige layer exists to hold them.

## Open questions to decide later
- What's the prestige currency, and what does it buy (flat multipliers? unlock skips?
  auto-completion of early tiers?).
- What milestone after Recursion unlocks World 2?
- Do the existing 4 "reset layers" stay as-is, or does one of them (Spiral?) get
  reconceived as the first real prestige layer?
- How does the Automation Grid (already planned in Spiral) relate to prestige — is it the
  "auto-max the early game" mechanism that makes re-climbing fast?
